Python это язык программирования, который любят за простоту и читаемость. Его используют в веб-разработке, анализе данных и автоматизации. Python часто выбирают первым языком, потому что код на нём похож на обычный английский текст. Начинающему программисту проще сосредоточиться на задаче, а не на сложном синтаксисе.

Docker позволяет упаковать приложение вместе со всеми зависимостями в контейнер. Контейнер запускается одинаково на любом компьютере, и поэтому фраза «у меня работает» перестаёт быть проблемой. Образ собирается по инструкции из файла Dockerfile. Для запуска достаточно одной команды, а порты контейнера можно пробросить наружу.

Git хранит историю изменений проекта. Каждый коммит это снимок кода с коротким описанием того, что изменилось. Ветки позволяют пробовать новые идеи, не ломая основной код. Репозиторий на GitHub служит резервной копией и портфолио, которое могут посмотреть работодатели.

Нейросети учатся находить закономерности в данных. Языковая модель получает текст на вход и предсказывает следующее слово. Чем больше данных и вычислений, тем лучше она справляется с вопросами. Однако модель может выдумывать факты, если не знает ответа, и это называют галлюцинациями.

Чтобы снизить галлюцинации, используют поиск по документам. Сначала текст режут на небольшие куски. Затем для вопроса находят самые подходящие куски и передают их модели вместе с вопросом. Такой подход называется RAG, и он позволяет отвечать по собственным данным компании.
