# Mini RAG: keyword chunk search

Небольшой учебный проект: читает текстовый файл, режет его на куски с перекрытием и по запросу находит самые подходящие куски. Это первая часть RAG-пайплайна, этап поиска (retrieval), реализованный без внешних библиотек.

## Как это работает

1. Файл `notes.txt` читается в строку.
2. Текст режется на куски по 50 слов с перекрытием в 10 слов (`chunk_text`).
3. Для запроса и каждого куска считаются частоты слов (`word_freq`): регистр и знаки препинания игнорируются.
4. Оценка куска: сколько раз слова из запроса встретились в нём (для нескольких слов вхождения складываются) (`chunk_score`).
5. Куски с нулевой оценкой отбрасываются, остальные сортируются от лучшего к худшему, возвращаются первые `k` (`search_chunks`).

## Запуск

Сторонние библиотеки не нужны, только Python 3.

```bash
python3 retrieval.py
```

Рядом должен лежать `notes.txt` (UTF-8). Запросы для проверки заданы в конце `retrieval.py`.

## Пример

Для текста из 203 слов получается 5 кусков. Запрос `"docker"` возвращает два куска, где говорится про контейнеры, и оба с оценкой 1:

```python
search_chunks("docker", chunks)
# [(1, 'Python это язык программирования ... Docker позволяет упаковать приложение вместе со'),
#  (1, 'не на сложном синтаксисе. Docker позволяет ... Git хранит историю')]
```

Запрос, которого в тексте нет, возвращает пустой список:

```python
search_chunks("кошка", chunks)
# []
```

## Ограничения

- **Только точные совпадения слов.** «данные» и «данных» для метода разные слова, поэтому запрос `"нейросети данные"` совпал лишь по слову «нейросети».
- **Нет понимания смысла.** Запрос «машинное обучение» не найдёт кусок, где написано «модели учатся».
- **Куски режутся по числу слов**, а не по границам предложений или абзацев, поэтому мысль может оказаться разрезанной между кусками.

## Что дальше

- Эмбеддинги вместо частот слов: сравнение по смыслу, а не по буквам
- Косинусная близость между векторами запроса и кусков
- Передача найденных кусков языковой модели и генерация ответа
- Нарезка по предложениям
- Простая оценка качества поиска на наборе тестовых вопросов
